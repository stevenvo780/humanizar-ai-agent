# ¿Cómo se registra una venta de lentes?

Desde el módulo 'Ventas' selecciona 'Nueva venta', busca al cliente por documento o crea uno nuevo, agrega los productos (montura, lunas, servicios) desde el inventario, aplica descuentos si aplica y confirma el pago. El sistema genera automáticamente la factura y descuenta el stock.
